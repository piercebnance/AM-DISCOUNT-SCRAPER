THE MOST WONDERFUL AMAZON SCRAPER

This is a site that scrapes Amazon for discounted products based on your search queries. It's hosted on a FastAPI framework
and is backed by Python. ScrapingBee API handles the scraping as it's authorized to be used on Amazon and affiliated websites.

PLEASE DONT OVERLOAD QUERIES, IT WILL GIVE YOU THE ERROR PAGE AND YOU WILL HAVE TO START OVER.

This project was completed over the course of 3-4 weeks with the help of tutorials and Claude code. The reason for the lack
of commits is because I didn't originally have this project uploaded to GitHub.
